# Forza Horizon 6 Countdown Site

This is a fan-made countdown website built to track the hypothetical release of *Forza Horizon 6*.

## About
This project uses an embedded TickCounter widget to display a live countdown timer. It is not affiliated with or endorsed by Playground Games or Xbox.

## Features
- Live countdown timer
- Simple responsive HTML layout
- Lightweight design for fast loading

## Disclaimer
This is a fan project. *Forza Horizon 6* has not been officially announced or confirmed.
